# Constraints

Fill in the limits for the active research project:

- Maximum number of smoke and full experiments.
- Kaggle GPU and wall-clock budget.
- Per-run timeout and storage limits.
- Stop conditions for success, exhaustion, or repeated inconclusive results.
- Forbidden shortcuts, leakage risks, and invalid evaluation practices.

Jobs must always have a finite timeout. Credentials and private keys must never enter source packages, run artifacts, datasets, or remote kernels.
